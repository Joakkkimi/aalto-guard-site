# UI Prototype

Generate several radically different UI variations on a single route, switchable from a floating bottom bar. The user flips between variants in the browser, picks one, then throws the rest away.

## Key Rules
1. Generate radically different variants (default 3-5 variants).
2. Keep them switchable via a floating bottom bar and `?variant=N` URL parameter.
3. Keep the transitions ultra smooth and responsive.
